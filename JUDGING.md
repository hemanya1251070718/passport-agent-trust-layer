# Hackathon Judging Criteria Alignment

| Judging Criterion | Required Benchmark | Passport Implementation & Proof |
| :--- | :--- | :--- |
| **1. Problem Fit & Impact** | Real-world necessity for autonomous agents | Solves the core blocker for agent autonomy: giving agents safe identity, spend limits, and revocable permissions without handing over master credentials. |
| **2. Technical Depth** | Orchestration, tools, architecture | Full-stack FastAPI + Next.js, cryptographic delegation tokens, deterministic policy engine, and MCP server architecture. |
| **3. Reliability & Evaluation** | Evals, guardrails, graceful failure | 50+ adversarial red-team test suite, fail-closed security guarantees, automated regression tests with Keploy. |
| **4. Product & Experience** | Polished UI, human controls | Real-time human dashboard with one-click approval cards, instant kill switch, and live spend telemetry. |
| **5. Demo & Communication** | Clear, reproducible, deterministic | Governed errand demo with live prompt-injection interdiction and traceable audit chain. |
